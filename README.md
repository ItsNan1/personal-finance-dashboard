# FinTrack

A simple, lightweight personal finance dashboard and budget predictor built using vanilla JavaScript and HTML. It lets you track your daily income and expenses and projects your future savings over 6, 12, and 24 months based on your current habits.

## Features
* Track income and expenses
* Real-time calculation of your net balance
* Dynamic projections showing future savings trends
* Mobile-friendly, responsive design

## How to Run Locally
1. Clone or download this repository.
2. Open the `index.html` file directly in any web browser.
